NEXT_STEPS — 再開時の具体作業（2026-09-28 時点）

■ 再開手順
1. cd 012-quote-order-invoice-app && npm ci
2. npm run db:local            （ローカルPostgreSQL 16 を port 54329 で起動、dev/test DB作成）
3. npm run typecheck && npm test && npm run test:e2e   （全件成功が前提）
4. PROGRESS.md / TEST_REPORT.md を確認

■ 既知の注意
- ヘッドレスChromium（検証環境）では Playwright の download.suggestedFilename() が常に "download" になる。
  ファイル名は Content-Disposition ヘッダで検証している（アプリ側の不具合ではない）。
- Noto Sans JP は pdf-lib のサブセット化でグリフが欠落するため使用しないこと（DECISIONS.md「PDF」）。
  フォントを変更する場合は tests/pdf-glyph-check.ts による検査が通ることを確認。
