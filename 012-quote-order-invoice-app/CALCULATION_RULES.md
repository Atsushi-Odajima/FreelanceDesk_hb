# CALCULATION_RULES — 金額・丸め・状態

実装：`shared/calc.ts`（画面とサーバーで同じコード）、テスト：`tests/unit/calc.test.ts`。

## 1. 入力の単位
| 項目 | 形式 | 範囲 |
|---|---|---|
| 単価・値引き・追加費用・入金額 | 整数円 | 0〜10億円（入金は1円以上） |
| 数量 | 10進文字列、小数3桁まで | 0 < 数量 ≤ 999,999.999 |
| 税率 | 10進文字列（%）、小数2桁まで | 0〜100（10 / 8 / 0 など任意入力） |
| 合計 | 整数円 | 1兆円未満 |

浮動小数は使わず decimal.js で計算。

## 2. 明細金額
`明細金額 = 端数処理(数量 × 単価, 明細の端数処理)`
- 明細の端数処理：四捨五入（既定）／切り捨て／切り上げ（書類ごとに選択）
- 例：1.5 × 333 = 499.5 → 四捨五入 500 / 切り捨て 499

## 3. 値引き・追加費用
- 書類単位で入力（正の金額）。それぞれに「対象の税率」を指定。
- 税率ごとの対象額 = その税率の明細金額合計 + 追加費用 − 値引き
- 対象額がマイナスになる値引きはエラー。

## 4. 消費税（税率ごとに1回だけ端数処理）
- 税の表示「税抜価格（外税）」：`税額 = 端数処理(対象額 × 税率 / 100)`、`合計 = Σ対象額 + Σ税額`
- 税の表示「税込価格（内税）」：単価は税込として扱い `税額（内訳）= 端数処理(対象額 × 税率 / (100 + 税率))`、`合計 = Σ対象額`
- 消費税の端数処理：切り捨て（既定）／四捨五入／切り上げ
- 例（外税・切り捨て）：1,001円＋1,001円（10%）→ 2,002 × 10% = 200.2 → 200円（明細ごとではなく税率ごとに1回）

※ 税務上の取扱い（インボイス制度の記載要件、源泉徴収等）への適合は保証しません。

## 5. 書類に表示する金額
小計（明細合計）、値引き・追加費用（明細）、税率別の対象額と税額、合計（税込）。PDFに端数処理の方法を注記。

## 6. 入金状態（金額から導出）
```
割当額 = 請求書に割り当てた入金の合計
残額   = 請求額 − 割当額（マイナスは過入金額）
状態   = 割当額 = 0        → 未入金
         0 < 割当額 < 請求額 → 一部入金
         割当額 = 請求額     → 入金済み
         割当額 > 請求額     → 過入金（差額を自動で値引き・手数料にしない）
期限超過 = 状態が 未入金 または 一部入金 かつ 支払期限 < 今日（Asia/Tokyo）
```
- 支払期限当日は期限超過ではない（翌日から）。
- 1件の入金を複数の請求書へ分割割当できる。入金の未割当額を超える割当は拒否。
- 請求額0円の請求書は入金済み扱い。

## 7. 訂正
- 確定済み請求書は上書きしない。訂正版（第2版…）を作り、確定時に旧版は「訂正前」になる。
- 訂正後の金額が**割当済み入金額を下回る場合は確定を拒否**（先に割当を見直す）。
- 履歴：訂正理由・旧金額・新金額・確定日時。請求番号は同じ。

## 8. 案件状態
問い合わせ → 見積作成中 → 見積提出 → 検討中 → 受注 → 作業中 → 納品待ち → 納品済み → 請求済み → 完了 ／ 失注 ／ キャンセル
- 操作に伴う**自動前進**：見積作成→見積作成中、提出→見積提出、受注→受注、納品→納品済み、請求確定→請求済み。後戻り・完了/失注/キャンセルからの自動変更はしない。
- 手動変更はいつでも可能で、すべて履歴に残る。状態変更だけで書類は作られない。
- 完了は自動にしない（全額入金時に「案件を完了にする」を提案）。

## 9. ダッシュボード金額（合算しない）
| カード | 定義 |
|---|---|
| 見積中金額 | 現在：受注前（見積作成中/提出/検討中）の案件の最新確定版の合計 |
| 受注金額 | 期間内の受注日の有効な受注額 |
| 請求済み金額 | 期間内の請求日の発行済み請求額（取消を除く、訂正後の額） |
| 入金済み金額 | 期間内の入金日の入金額（未割当分を内訳表示） |
| 未入金残額 | 現在：発行済み請求の残額合計（過入金は0として扱う） |

## 10. 要対応リスト
- 見積回答待ち：状態が見積提出/検討中で受注がなく、提出済みの版がある案件
- 今週納期：予定納期が今週（月〜日）以前で未納品の案件（受注済みの遅れを含む）
- 納品待ち：有効な受注があり納品記録がない進行中の案件
- 未請求：有効な受注と納品記録があり、発行済み請求書がない案件（下書きは未請求のまま）
- 今月支払期限：今月が期限で残額がある請求
- 期限超過：上記定義
- 未割当入金：未割当額が残る入金
